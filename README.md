# Morpion

Petit jeu de morpion (tic-tac-toe) en Python, jouable à 2 en ligne de commande.

## Lancer le jeu

```bash
python3 morpion.py
```

## Règles

- Joueur **X** commence.
- Entrez un nombre entre **1 et 9** pour choisir la case.
- Le premier qui aligne 3 symboles gagne.
- Si la grille est pleine sans gagnant, c'est un match nul.
