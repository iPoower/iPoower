# Node 24 LTS pour les tâches Race Control

Les sept workflows qui exécutent Node configuraient treize étapes en version 20.
Le calendrier officiel de Node.js donne le 30 avril 2026 comme fin de support
pour cette version. Node 24 est LTS et son support est prévu jusqu’au 30 avril 2028.
Sources : https://nodejs.org/en/about/previous-releases et
https://github.com/nodejs/Release/blob/main/schedule.json.

La correction change uniquement node-version de 20 à 24 dans ces étapes.
Les versions des actions sont traitées par les PR Dependabot séparées.
Aucun script applicatif, algorithme cryptographique, réglage, secret, droit,
condition de validation ou mécanisme de publication n’est modifié.

La non-régression réexécute les tests existants dans le nouveau runtime :
unitaires, fixtures, chiffrement et sauvegardes fictives, relais, matrice complète
Chromium/WebKit, QA et profilage lorsque leurs filtres s’appliquent.
Le build local sous Node 24 et prod-83 publiée sous Node 20 sont identiques :
build dbb5b31b3de3, SHA-256
a211bb69d184d0b52753f172fe4e9b87f7a06b302534dd2d256df4fc9db6fa29.
Cette égalité a été vérifiée sur les octets HTTP réellement servis.
Vérifier que la publication post-fusion sous Node 24 conserve ces mêmes octets.

Les contrôles avec les clés réelles restent confinés au job de confidentialité
post-fusion ; aucun test destructif ou accès aux données personnelles locales
n’est nécessaire. Les étapes de relais, contrôle des sources et watchdog
sont aussi vérifiées après fusion.
